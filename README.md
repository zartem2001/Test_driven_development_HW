# Разработка через тестирование (TDD) — Телефонная книга

## 📋 Описание задачи

Разработать класс `PhoneBook` через подход **Test Driven Development (TDD)**. 
Класс должен поддерживать операции:

- `add(name, number)` — добавить контакт. Возвращает количество контактов после добавления. Повторяющиеся имена не добавляются.
- `findByNumber(number)` — найти имя по номеру **без полного перебора**.
- `findByName(name)` — найти номер по имени **без полного перебора**.
- `printAllNames()` — вывести все имена **в алфавитном порядке без сортировки**.

## 🎯 Цель

Отработать:
- Подход **Test Driven Development** (Red → Green → Refactor);
- Написание тестов **до** реализации;
- Поэтапные коммиты по TDD-циклу;
- Использование подходящих структур данных для быстрого поиска.

## 🛠️ Используемые технологии

- Java 17+
- Spring Boot
- JUnit 5
- `TreeMap`, `HashMap`
- Maven
